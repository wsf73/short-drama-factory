<h1 align="center">🎬 Short-Drama Factory v4.4</h1>
<p align="center"><b>抖音 / 红果 爆款短剧工业化编剧超级系统 · 纯剧本引擎</b></p>
<p align="center"><sub>基于 <a href="https://github.com/lixiaoxiao9888-create">lixiaoxiao9888-create（漫剧老李）</a> 原创项目二次开发 · 由 <a href="https://github.com/wsf73">wsf73</a> 维护</sub></p>

> **一句创意进，一部带付费墙的爆款剧本出。**
> 情绪契约贯穿全剧，矛盾按单元跑——单矛盾绝不烧过 30 集；篇幅可选标准 / 长档（150~195 秒弹性）/ 漫剧；台词 / 内心独白 / 旁白三通道分流。
> 只产剧本层，不碰分镜 / 资产 / 视频制作。

---

## 篇幅三档

| 档位 | 单集时长 | 正文体量 | 单集拍数 | 全剧集数档 |
|---|---|---|---|---|
| 标准档（默认） | 90～120 秒 | 480～850 字 | 1 拍 | 60 / 80 / 100 |
| **长档** | **150～195 秒** | **820～1400 字** | **双回合 + 中段小钩** | **30 / 40 / 50** |
| 漫剧档 | 60～90 秒 | 330～620 字 | 1 拍 | 60 / 80 / 100 |

> 长档不是注水拉长：一集必须装**两个往返回合**（施压与反驳各升一档）+ ≈90 秒处**中段小钩**；全剧按内容量守恒折算（1 长档集 ≈ 2 标准集），四幕、单元链、付费墙同步换算。

---

## 核心方法论

**情绪契约单元链**——全剧锚定的是观众每集要续期的"那口气"，矛盾只是单元载具：

- 🎯 **单矛盾硬帽 20～30 集必闭环**（长档折半 10～15 集；60 集 = 2～3 单元 / 80 集 = 3 / 100 集 = 3～4）
- 🔄 **三缝合一换矛盾**：旧单元残渣生新矛盾（火种埋钩）/ 对手换层不换欲 / 弧光随单元升级——换矛不断气
- 📊 **每单元一张往返回合表**：六档证据阶梯 × 六档反驳成本阶梯，单元间靠情绪契约接力
- 💰 **付费墙挂单元接缝**：换矛盾点即天然强付费点；中点攻守转换对位第一付费墙

## 快速开始

```bash
# 安装到技能目录后直接对话："写短剧" "立项：赘婿战神" "/长档大纲 40集" "/连写 1-5"
# 命令按 Windows 写 python；macOS / Linux 用 python3
python scripts/validate_episode.py --self-test
python scripts/validate_episode.py examples/long-format-3min-demo.md --format long
python scripts/validate_series.py --self-test

# 参考图配额（E24）：接 AI 视频生成时，单集「场景数 + 人物数」须 ≤ 5（每张参考图 = 一景或一人）
python scripts/validate_episode.py <单集.md> --ref-images 5   # 上限可调；0 = 关闭本项检查
```

> **选哪个模型写？** 写剧本的第一标准是**指令遵循与长程一致性，不是文笔**——格式跑偏直接机检 FAIL，
> 文笔则由本 skill 的规则库兜底。清单与依据见 `references/model-selection.md`。
