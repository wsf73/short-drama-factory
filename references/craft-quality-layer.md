# 戏剧工艺层（通用质量底座 · 红果适配版）

> **定位**：本文件补的是**机检照不到的那一层**——"结构合规但戏是假的"。机检（`validate_episode.py`）只能查体量、场景数、断章落位、复读、红线词；它查不出"人物被情节推着走""对白只是把同一个结论越说越清楚"。本层专治这个。
>
> **触发**：写新集正文前、处理"平铺直叙/人物只在执行任务/情绪浮在台词表面"、连续两次修改同一条仍不见改善、以及长档双回合写得像两段平行事件时，**必读**。
>
> **来源**：整合自外部包 JYY v3.8 的 quality-baseline、dramatic-generation 两份参考及 jyy-script-creation-v2 的产品模式部分（均为**外部源文件，不在本包内**，勿按包内路径查找），按红果竖屏单集体量改写；未采纳项见文末「迁移边界」。

---

## §〇 分层原则（最重要，先读这条）

本 skill 有两层规则，**冲突时永远是硬约束赢**：

| 层级 | 内容 | 性质 |
|---|---|---|
| **外层·红果平台适配** | 档位体量、场景上限、黄金前 3 秒、每集断章、付费墙区间、单句上限、合规红线 | **硬约束**，机检强制，不得以"质量优先"绕过 |
| **内层·戏剧工艺** | 本文件全部内容：因果是否成立、人物是否有判断、结果是否进入下一次选择 | **质量层**，用于诊断与生成，不新增数量配额 |

**一句话**：外层保证"这是能上红果的短剧"，内层保证"这是戏而不是大纲标签的扩写"。两层都要，但外层不能被内层推翻。

本层**不新增任何硬指标**——不加"每集必须几场""每集必须几次反转""每集必须几句金句"。看到下面的问题清单，是让你去**找戏**，不是让你去**凑数**。

## §一 先辨真瓶颈：五问定因

用户说"没画面、没张力、台词没意思、不连贯"时，**不要直接加字、加动作、加吵架**。先按顺序过这五问，定位到哪一环断了：

1. **人物此刻是否有一个清楚的即时目标？**（不是"想复仇"，而是"这一场他要让对方做什么/交出什么"）
2. **阻碍是否主动作用在这个目标上？**（对方有自己想要的，不是站着等他表演）
3. **人物是否被迫做出选择？**（而不是自动执行了正确答案）
4. **结果是否改变了什么？**（信息 / 关系 / 资源 / 位置 / 危险 / 身体 / 资格 / 认知）
5. **下一场是否由这个结果触发？**（而不是"接着往下演"）

- 五问任一缺失 → **优先修因果与场面功能**，不要碰画面浓度和对白质感。
- 五问全部成立、但读起来仍平 → 才轮到画面浓度、对白质感、语言节奏。

**关键行动还要补一句自检**：观众看不看得见他"为什么相信这个办法有用"？其他选项为什么被忽略或代价更高？结果出现后他认出、误读还是否认了什么？

> ⚠️ 只补一个动作、没让它受到反作用、没产生后果、没进入下一次选择 —— **因果链仍然没修好**，哪怕机检已经全过。

## §二 戏剧生成链（写场前在内部跑一遍，不进正文）

承重场写前，用这条线找戏：

```text
上一结果造成的压力
  ➔ 人物当前判断／误判（可以有自欺、侥幸、嘴硬）
  ➔ 他认为可行的办法（必须能执行，不是一种心情）
  ➔ 对方或规则的反作用
  ➔ 可见代价或意外收益
  ➔ 人物认出、否认或误读结果
  ➔ 下一次选择
```

**这是一条因果诊断线，不是七段式正文模板。** 平静相处、照料、等待、纯喜剧、情绪余波不必补齐每一项；但**承重场若只有"人物做了一件事"——没有依据、没有反作用、没有改变、没有后续，就还没写完这场戏。**

尤其检查三种高频失败：**善意的坏结果 / 冲动反击 / 错误选择**——

1. 观众能否从已经出现的信息与情绪，看懂他为什么相信这个办法有用；
2. 更稳妥的办法是否有他当下不愿承受的代价，或根本不在他的认知范围内；
3. 他的行动是否真的改变了别人、资源、风险、关系或信息——而不是只证明作者写过一个动作；
4. 结果出现后，他是否看见了足以影响下一步的东西。**他可以继续嘴硬或误判，但不能像结果没发生过。**

> **人物不必理智或最优。** 可信来自"这个人此刻为什么会这么选"，不来自选择正确。给他一个次优但心理可理解的选择，比给他一个正确但无来由的选择好看得多。

## §三 单场成立七问

每个承重场跑一遍：

1. 谁在争取什么？
2. 为什么**必须此刻**争取？（拖延的代价是什么）
3. 谁或什么在阻碍他？
4. 他采取了什么**具体策略**？
5. 阻碍如何**反作用**？
6. 结果与他的预期**偏差**在哪？
7. **场末相较场初改变了什么？**（信息/关系/资源/位置/危险/资格/身体/承诺/下一选择）

第 7 问是命门。若人物从怀疑开始、争论完仍以**同样的怀疑和同样的办法**离开——这场就是空场，优先改行动关系，**不要靠把声音写大来充当推进**。

**例外（不算空场）**：气氛延宕、照料、日常、情绪余波场可以没有显性攻防，但必须拥有明确的情绪视角，并且改变关系、意义、身体状态、决定或观众期待中的至少一项。

### §三·补 集内结算（单集情绪出口）

竖屏单集必须给观众一个**可见的"出一口气"**：主角反将一次 + 反派为本次施压**付出可见代价**（当众失面／盘算落空／被架住进退两难）。

- 只堆受辱（哪怕冲突再密、证据再多）而不给结算 → 观众的情绪出口被堵死，结尾断崖；
- **密度由戏定（不是阈值）**：密度是场景功能的副产品——攻防场该说满、危机/动作场让画面说、转场与余波可极简；集内天然忽密忽疏。机器只能粗筛（体量宽参考带）与报警失衡（E19 连续对白≤95字 / E21 对白占比≤70%），**不能拿总字数当目标**（否则逼出注水）；"这一段该给多满"是工艺判断，不是数值。
- 判据一句话：把这一集从头看到底，**反派有没有为她的施压付账**？没有，就是"直线受辱"；
- 与 §三 第 7 问（场末相较场初改变了什么）的区别：第 7 问看"场有没有空转"，本补看"**观众有没有出口**"——两者都要。
- 机检查不到这一层（它只度量），故列为 SKILL Step 3 的**写后门禁**，并在单集模板落成【本集结算】字段。
- **信号闭环（硬）**：伏笔/异能/玄学信号也要有结算——必须给「**信号 → 当场可验证 → 产生作用**」三步。**严禁拿观众看不懂的暗号判胜负**（如"纸哭了/不哭了"）：规则没在剧内建立就用它下判断，观众只会懵。写法：让信号指向一个**具体、当场可验证的事实**，再由主角当众验证并当武器用（例：小满说"那张纸在念我的名字"→ 知夏翻纸，抬头写着"被申请人：小满"）。

## §四 三线可见变化

竖屏信息量低，观众靠**可见物**跟状态。全程维护三条线，让它们在本集内有可指出的变化：

| 线 | 追踪什么 | 本集至少要回答 |
|---|---|---|
| **身体线** | 伤势、呼吸、站姿、能否起身、距离与接触 | 谁的身体状态变了？变了之后他能做什么、不能做什么？ |
| **空间线** | 相对出口、危险源、关键地标、彼此的站位 | 权力关系变化有没有落到位置上（谁退、谁逼近、谁被挡在门外）？ |
| **道具线** | 关键物件从哪来、在谁手里、状态怎么变、最后去哪 | 本集的"铁证/信物/条子/存折"结束后在谁手上？ |

**优先写多功能画面**：一个动作同时推进危险、暴露性格、改变关系、留下线索。删掉之后不影响事件、人物、情绪、后续的动作 = 冗余候选。

**禁止拿这些假装有画面**：
- 连续堆光影、风声、湿气、颜色、天气；
- 静态奇观长时间只供人物和观众观看；
- 未建立依据的道具特殊功能，首次出现就解决核心困难（普通工具的常规用途不必铺垫）；
- 动作已经展示后，对白无交流、无情绪作用地重复同一信息；
- 用"他意识到""她明白了""气氛压抑"等**作者结论**代替可见反应。

## §五 因果接力

每个转场尝试写成一句话：

> 因为上一场发生了 X，人物现在必须去 Y 做 Z，否则会失去 W。

- 观众能凭既有目标稳定推断的路程**可以省略**；
- 导致行动目标、人物位置、道具归属、规则状态发生改变的必要桥梁**不能省略**。
- **一次转场若同时改变时间、地点、人物、目标、关键道具、事件类型中的三项以上，必须保留至少一个接力线索**：持续动作 / 同一道具 / 同一伤势 / 同一声音 / 同一问题 / 一句明确动机。

> 短剧高频翻车点：第 2 集换到"三年后""另一个城市""换了一批人物"，却没有一个可见的接力物。**这种跳变会让完播断崖。**

## §六 概念负荷最小登记（时代 / 世界观设定密集项目专用）

设定密集的剧一集要交代时代/世界观背景、组织关系、称谓、物价或规则专名。对每个新名称做最小登记：

```text
名称 / 此刻是否必须知道名字 / 先看见的作用或后果 / 与旧概念的区别 / 预计再次使用 / 处理
```

`处理`只选一项：**现在命名 / 先用大白话 / 先演后命名 / 合并旧概念 / 延后 / 删除**。

- 规则与设定**尽量在第一次影响选择时出现**：人物触犯、利用、误解或被它限制，观众从后果理解规则；
- 当前决策不需要的规则**延后**；同一结论被专家、物证、回忆重复证明时，**保留最有戏的一次**，其余改成新作用或合并；
- 一个陌生名称若只让世界显得丰富、后文不再使用 → 删名，或改成普通描述。

**成稿后自测**：遮住所有专名，若仍能复述"眼前谁要做什么、谁占上风"，说明专名没有阻断理解；若遮住后什么都不懂 → 检查是专名必要、建立不足，还是规则本身太多。

## §七 远简近详的写作状态包（连写 60～100 集防走形）

批量连写时，**每一集只携带当前范围需要的信息**，不要把全套人物小传、评审清单、未来谜底同时塞进每一集：

- 全剧故事发动机 + 不可变事实（时代、城市、家庭构成、金手指设定）；
- 较远阶段的简要方向（不展开）；
- **最近一到两集的实际结果**、关键原文、尚未消失的身体／道具／关系状态；
- 当前集双方的目标、认知、隐瞒、预期转折；
- 本集主导变化、阶段兑现、下一压力。

配套纪律：**台账记事实，状态包记"生成时要带着什么"**——两者分工不同，别用台账替代状态包（台账是给人对账的，状态包是给写正文用的）。

> 这条是连写不串味、不变形的最有效手段。写第 40 集时把第 1 集的全部细节都拖进来，只会让模型抓错重点。

## §八 七级修订顺序

发现多个问题时，按影响排，不按"好改的先改"：

1. 前后接口与硬事实（时代、人名、时间线、道具归属）；
2. 人物动机、信息权限、空间连续；
3. 单场功能与单集／单元闭环；
4. 敌我策略与代价；
5. 情绪节奏与余波；
6. 对白自然度、角色声音、趣味；
7. 格式、错字、标记、屏幕文字清单。

- 这是**常用排查顺序**，按本次核心失败调整；
- **不要用漂亮台词掩盖没解决的因果问题**；
- 情绪或对白若是本次核心失败，可以提前，不必死守顺序。

**A/B 修改法**：某场反复写不平时，生成 **2～3 个因果上真正不同**的实现（改"人物为何会选、对方如何反应、结果怎样改变下一步"），比较后取一。**只换道具、地点或金句不算不同方案。**

## §九 竖屏落点（把工艺层翻成可拍的画面）

本层是剧本层，不做分镜，但**写到能演**是底线：

- 动作写"能演出来的"：保留决定理解的对象、阻力、结果和反应；
- 同目的的连续微动作**可以合并**，普通操作**不要写成逐帧解说**；
- 对白与动作**不设比例**：已经展示的事实不无功能地复述；不把删掉的台词等量换成环境、旁白或动作；
- 简短表达**不能删掉基本主语、因果与现场反应**；
- 微表情只写**生理可观测动作**（喉结滚动、指甲掐进掌心、耳根发红），不写"他内心五味杂陈"。

> **与独白通道的分界（v3.4）**：上面"不写内心五味杂陈"约束的是 **△ 动作行**——心理描写不许塞进动作行。它**不构成对独白的禁令**：独白是独立通道，走 `内心独白：`／`旁白：` 格式行，配额与写法见 `references/inner-monologue-vo.md`。判据一句：**△ 不写感受；独白只写具体的账。**

## §十 禁止事项（工艺层专属）

1. 用作者结论（"气氛压抑""他明白了"）代替可见反应；
2. 用抽象名词、结果摘要代替关键过程；
3. 让多场依次汇报线索，没有谁因为线索改变做法；
4. 用对白承担本应由事件完成的全部转变；
5. 借无知情依据的旁人（医生、师爷、邻居、专家）替作者讲主题、判断关系、宣布完整真相；
6. 为了"有戏"给安静成立场强加争吵、反转或解释性对白；
7. 把每个情绪层次都推到极点（人物会全程同一音量，高潮反而消失）。

## 迁移边界（哪些没采纳，为什么）

| JYY 原项 | 处置 | 原因 |
|---|---|---|
| "每集至少三个有效场景" | **不采纳** | 该条实为 JYY 包内某用户的**个人项目约定**（其文件自述"不是短剧行业通用规律"），与红果标准档单集场景 ≤2 直接冲突 |
| "不统一规定首集耳光、前三秒、每三秒一次刺激" | **不采纳** | JYY 作为跨行业通用层，对无依据阈值保持谨慎是对的；红果硬阈值有平台实搜热剧数据支撑，属**平台适配层**，不是无依据 |
| "不擅设第 10/20/30 集付费" | **不采纳** | 我们有 `hongguo-beat-sheet.md` 的三级付费墙区间；仅在**换平台或换总集数**时按新口径重算 |
| 北美英语 / 多语本土化整套 | **不采纳** | 红果场景用不到；仅在做方言项目时，借用其"地区未校准工作稿"的降级纪律 |
| 三级情绪结构（全剧承诺／分集情绪债／关键场设计） | **部分并入** | 全剧层我们已有`emotion-flow-roundtrip.md` 情绪契约；本层只取"关键场写前只抓触发与利害、各方理解、可见选择与代价、对方反应、观众推断、新状态" |
| 概念负荷最小登记、远简近详状态包 | **采纳** | 直接对应我们"设定密度高""连写 60～100 集"两个真实痛点 |
| 戏剧生成链、单场七问、三线变化、因果接力、七级修订顺序 | **采纳改写** | 补齐我们"机检全过但戏假"的能力空白 |
