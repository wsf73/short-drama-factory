# 参考图配额（单集 场景数 + 人物数 ≤ N）

> **一句话**：下游 AI 视频生成时，**每张参考图 = 一个场景或一个人物**；单集能投喂的参考图有硬上限
> （默认 **5**）。所以剧本端必须保证 **单集「场景数 + 人物数」≤ 5**，否则一次出图放不下。
>
> 机检项：**E24**（`validate_episode.py`，FAIL 级）。规格权威：本文件。

---

## 一、为什么有这条约束

这是**生产侧**约束，不是剧作侧约束——它不回答"戏是否成立"，只回答"这集能不能被一次生成出来"。

- 生成管线（Seedance / 即梦 / Kling / Vidu 等 + 垫图工作流）单次最多挂 **N 张参考图**（常见 N=5）。
- 一张图要么锁**场景**（环境/空间/光线），要么锁**人物**（脸/服装/体型）。
- 因此单集里出现的 **场景种类数 + 人物种类数**，直接等于这集需要的参考图张数。
- 超了会怎样：要么人物变形（换脸/换衣服）、要么场景漂移（同一个客厅变成三个客厅）、要么被迫裁角色。
  **三种都是废镜。**

> 注意：**出场但不入名册的群像/背景人物**（"满堂人""保镖们""围观的"）**不占配额**——
> 它们不需要独立参考图。配额只数 **`[场景]` 行** 与 **`[人物]` 名册条目**。

---

## 二、计数口径（与机检 E24 完全一致）

```
参考图张数 = scene_count(text) + roster_count(text)

scene_count  = 匹配 ^\[场景\] / ^【场景】 / ^## 场景 的行数
roster_count = 所有 [人物]： 行，按 、，,／/ 切分，剔除括号备注后的非空条目总数
```

**关键口径**：

| 项 | 是否计入 | 说明 |
|---|---|---|
| `[场景]：内景·客厅·日` | ✅ 计 1 | 每条 `[场景]` 行 = 1 张环境参考图 |
| `[人物]：赵长顺、李芳、老周` | ✅ 计 3 | 每个名册条目 = 1 张人物参考图 |
| `[人物]：林辰（隐忍龙王）` | ✅ 计 1 | **括号内备注剔除**，只算名字 |
| 正文里出现但不在 `[人物]` 的角色（"经理""保镖""满堂人"） | ❌ 不计 | 群像/背景不占配额 |
| 同一个人物重复出现 | ✅ 只计 1 | 名册是"种类"清单，不是出场次数 |
| 画外音/转述里提到的人名 | ❌ 不计 | 不出镜就不需要参考图 |

## 三、超限了怎么改（按优先级，从轻到重）

**核心原则：砍的是"功能位"，不是"戏"。** 一个角色如果只是来递个东西、报个价、宣个规，
他不需要一张独立的脸——把功能并到已有角色身上，戏一点不损。

### ① 合并同类工具位（首选）
同类功能位合成一个代表，名册只留一个名字。
- 中介甲 + 中介乙 → **中介**
- 摊主甲 + 摊主乙 → **摊主**
- 护士 + 前台 → **护士**
- 效果：人物 −1 ~ −2，**零改写成本**（正文里对应台词改口即可）。

### ② 把无台词角色降为"只剩光与动作"
没有台词、只提供画面信息的角色，不必进名册——写成**动作/画外**。
- `[人物]` 删掉"小满" → 正文写 `△ 里屋的灯亮着，一个人影动了动。`
- 递纸条的邻人 → `△ 门缝里塞进来一张纸条。`（手写说明即可，人不入场）
- 效果：人物 −1，**信息不丢**（动作与物证承担了原本的叙事功能）。

### ③ 把台词转给已出场角色（承接改写）
工具位的台词直接改口给已有角色；若是"公职功能"（民警/法官/调解员），
保留其**功能的威严感**但不必让他成为名册人物——可改为**画外音**或**转述**。
- `调解员：按《民法典》第 xxx 条……` → 改为由已出场的周玉兰**自带小册子**念出来。
- 效果：人物 −1，合规的"公权力威严"由**引述条文**而非**具体公职角色**承载。

### ④ 合并场景（最后手段）
两条 `[场景]` 若本就是同一空间的连续动作（客厅→客厅门口），合成一条 `[场景]`。
- 效果：场景 −1。**仅在人物已无法再减时才用**——场景合并容易伤调度。

### ⚠️ 绝不能动的
- **承担伏笔/反转的角色**：任何角色只要他的**动作/台词是某条伏笔的埋点或回收**，删了他等于断账。
- **人物账里有档案的角色**：删名册不改台账 → 触发 S4（人物无档案）。
- **死人开口检查涉及的角色**（S3）。

> 判断法：动手前先问一句"**删了他，哪条伏笔/反转会断？**" 答不上来 → 可以降；
> 答得上来 → 换个角色降，或者去减场景。

## 四、机检 E24

```bash
python scripts/validate_episode.py <单集剧本.md> [--format standard|long|manju] [--ref-images N]
```

- **默认上限 5**，超限 **FAIL**。
- `--ref-images N`：改上限（例如你的管线能给 8 张，就 `--ref-images 8`）。
- `--ref-images 0`：**关闭**本项检查（纯剧本交付、不接生成管线时用）。
- 输出会多打一行：`参考图配额：场景 2 + 人物 3 = 5 / 5`，一眼可核对。

### 批量核对
写完一批，用下面这段一次性列出全体集的配额（或直接用 `_quota` 思路）：

```bash
# 逐集跑并抓 E24（0 行 = 全部合规）
for n in $(seq -w 1 80); do
  python scripts/validate_episode.py episodes/EP$n.md --format standard | grep -H "E24"
done
```

## 五、实战基线（《六十岁，我不伺候了》80 集）

- 首轮统计：**33/80 集超标**（人物名册普遍 5~7 人，最高 8）。
- 修复手法分布：**①合并工具位 ~12 集 · ②降为画外/动作 ~15 集 · ③台词承接改写 ~6 集**。
- 修复后：**0/80 超标**，且单集机检 80/80 PASSED、`validate_series` PASSED——
  **说明"减参考图"与"保伏笔/反转/连续性"可以同时成立**。
- 典型超标集与修法：
  - EP01~EP04（5 人）→ 删"小满"，改里屋灯光一笔带过。
  - EP02/EP05（中介甲+乙）→ 合并为"中介"，台账同步并表。
  - EP71（含公职功能位）→ 《民法典》改由周玉兰自带小册子念，公职角色不入名册。
  - EP80（2 场 + 6 人）→ 场景合 1，删 3 个收尾群像（王婶/三叔/陈志远，改背光侧影）。

## 六、和 E3 的关系

- **E3** 只管**场景**（标准档 ≤2 / 长档 ≤3），是"单集能不能在一两个空间里讲完"的剧作约束。
- **E24** 管**场景 + 人物之和**，是"这集能不能被一次生成出来"的生产约束。
- 两者独立，可能一个过、一个不过：2 场 + 4 人 = E3 过、E24 超。
- **口径优先级**：E3 是平台/剧作硬线，E24 是生成管线硬线；两条都要过。
