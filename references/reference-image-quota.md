# 单集配额（单集 场景（地点）数 + 出场人物数 ≤ 4）· 第一硬性规则

> **一句话**：单集「**场景（地点）数 + 出场人物数 ≤ 4**」是本系统的**第一硬性规则**，
> 全系统优先级最高——**优先于单集时长（E16/E17）、体量（E1）与一切工艺层**。
>
> 下游 AI 视频生成时**每张参考图 = 一个场景或一个人物**；单集能投喂的参考图有硬上限，
> v4.5 起剧本端统一按 **4** 卡死。任何集超限即 **FAIL，不得交付**。
>
> 机检项：**E24**（`validate_episode.py`，FAIL 级）。规格权威：本文件。
> **配额与时长冲突时，一律保配额、酌情调整单集时长（见 §四），严禁反向操作。**

---

## 一、为什么有这条约束

这是**生产侧**约束，不是剧作侧约束——它不回答"戏是否成立"，只回答"这集能不能被一次生成出来"。
v4.5 应生产侧要求，将其从 v4.4 的普通检查项（≤5）**收紧为 ≤4 并升格为第一硬性规则**。

- 生成管线（Seedance / 即梦 / Kling / Vidu 等 + 垫图工作流）单次最多挂 **N 张参考图**，本系统统一按 **N=4** 卡。
- 一张图要么锁**场景**（环境/空间/光线），要么锁**人物**（脸/服装/体型）。
- 因此单集里出现的 **场景种类数 + 人物种类数**，直接等于这集需要的参考图张数。
- 超了会怎样：要么人物变形（换脸/换衣服）、要么场景漂移（同一个客厅变成三个客厅）、要么被迫裁角色。
  **三种都是废镜。**

> 注意：**出场但不入名册的群像/背景人物**（"满堂人""保镖们""围观的""黑衫打手"）**不占配额**——
> 它们不需要独立参考图。配额只数 **`[场景]` 行** 与 **`[人物]` 名册条目**。

## 二、计数口径（与机检 E24 完全一致）

```
单集配额 = scene_count(text) + roster_count(text) ≤ 4

scene_count  = 匹配 ^\[场景\] / ^【场景】 / ^## 场景 的行数
roster_count = 所有 [人物]： 行，按 、，,／/ 切分，剔除括号备注后的非空条目总数
```

**关键口径**：

| 项 | 是否计入 | 说明 |
|---|---|---|
| `[场景]：内景·客厅·日` | ✅ 计 1 | 每条 `[场景]` 行 = 1 张环境参考图 |
| `[人物]：赵长顺、李芳、老周` | ✅ 计 3 | 每个名册条目 = 1 张人物参考图 |
| `[人物]：林辰（隐忍龙王）` | ✅ 计 1 | **括号内备注剔除**，只算名字 |
| 正文里出现但不在 `[人物]` 的角色（"经理""保镖""满堂人""黑衫打手"） | ❌ 不计 | 群像/背景不占配额 |
| 同一个人物重复出现 | ✅ 只计 1 | 名册是"种类"清单，不是出场次数 |
| 画外音/转述里提到的人名 | ❌ 不计 | 不出镜就不需要参考图 |

**≤4 口径下的常见构型**：

| 构型 | 配额 | 典型用途 |
|---|---|---|
| **1 场 + 3 人** | 4 | 长档主力构型（主角 + 对手 + 质疑者/证人） |
| **2 场 + 2 人** | 4 | 长档双空间对峙、标准档对手戏 |
| 1 场 + 2 人 | 3 | 标准档常规集 |
| 2 场 + 3 人 | 5 | **已超限，禁止**（v4.4 旧边界，v4.5 收紧） |
| 1 场 + 4 人 | 5 | **已超限，禁止**：先并功能位/降群像 |

## 三、超限了怎么改（按优先级，从轻到重）

**核心原则：砍的是"功能位"，不是"戏"。** 一个角色如果只是来递个东西、报个价、宣个规，
他不需要一张独立的脸——把功能并到已有角色身上，戏一点不损。

### ① 合并同类工具位（首选）
同类功能位合成一个代表，名册只留一个名字。
- 中介甲 + 中介乙 → **中介**
- 摊主甲 + 摊主乙 → **摊主**
- 护士 + 前台 → **护士**
- 效果：人物 −1 ~ −2，**零改写成本**（正文里对应台词改口即可）。

### ② 把无台词角色降为"只剩光与动作"（群像/画外）
没有台词、只提供画面信息的角色，不必进名册——写成**动作/群像/画外**。
- `[人物]` 删掉"小满" → 正文写 `△ 里屋的灯亮着，一个人影动了动。`
- 递纸条的邻人 → `△ 门缝里塞进来一张纸条。`（手写说明即可，人不入场）
- 有打斗的打手 → `△ 几名黑衫打手抡棍围上来。`（群像不占配额，动作照打）
- 效果：人物 −1，**信息不丢**（动作与物证承担了原本的叙事功能）。

### ③ 把台词转给已出场角色（承接改写）
工具位的台词直接改口给已有角色；若是"公职功能"（民警/法官/调解员），
保留其**功能的威严感**但不必让他成为名册人物——可改为**画外音**或**转述**。
- `调解员：按《民法典》第 xxx 条……` → 改为由已出场的周玉兰**自带小册子**念出来。
- 效果：人物 −1，合规的"公权力威严"由**引述条文**而非**具体公职角色**承载。

### ④ 合并场景（最后手段）
两条 `[场景]` 若本就是同一空间的连续动作（客厅→客厅门口、包厢→包厢门外走廊），合成一条 `[场景]`。
- 效果：场景 −1。**仅在人物已无法再减时才用**——场景合并容易伤调度。

### ⚠️ 绝不能动的
- **承担伏笔/反转的角色**：任何角色只要他的**动作/台词是某条伏笔的埋点或回收**，删了他等于断账。
- **人物账里有档案的角色**：删名册不改台账 → 触发 S4（人物无档案）。
- **死人开口检查涉及的角色**（S3）。

> 判断法：动手前先问一句"**删了他，哪条伏笔/反转会断？**" 答不上来 → 可以降；
> 答得上来 → 换个角色降，或者去减场景。

## 四、配额与单集时长冲突：保配额、调时长（v4.5 核心规程）

当 4 配额与**既定单集时长/档位**发生冲突——典型是长档（150～195 秒）双回合在 ≤4 内装不下，
或为满足时长必须加人、加场景——**一律保配额，酌情修改单集时长**。按下列顺序处理：

### 处理 A：压缩进 4 配额，时长随之缩短（首选）
用 §三 的四级修法把场景+人物压到 ≤4；压完后**按实际台词量与动作拍数重新倒推【本集时长】**
（口径见下；时长比原定短是允许的）。
- 例：原长档 2 场 + 4 人 = 6、标 170 秒 → 合并走廊场景、打手降群像 → 1 场 + 3 人 = 4，
  按实际台词量重标时长（如 150 秒）。

### 处理 B：把本集拆成两集（内容量确实大时）
4 配额装不下的内容量，**拆成前后两集**：每集各自 ≤4，各自有钩子、结算与断章；
台账同步登记拆集映射（原 EPn → EPn / EPn+1），后续集号顺延。
- 这是"**减单集配额、不减总内容**"的标准动作，优于硬压。

### 处理 C：配额裁定，按实际时长降档交付
压缩/拆集后本集仍以长档名头交付、但实际时长低于长档下限（150 秒）时，在头部字段**显式标注**：

```
【配额裁定】：配额优先，本集时长调整为 X 秒（按 standard 档交付）
```

- 机检识别该字段且含"**配额优先**"后：本集**按 standard 档校验交付**，
  **E17（长档 ≥150 秒）、E11（中段小钩）让位**，E16 不再以长档口径拦截；
- 输出会提示：`【配额裁定】第一硬性规则生效：保配额（场景+人物≤4），本集时长/档位已调整，按 standard 交付`；
- **裁定必须显式标注**：无字段时长档仍按 E16/E17 双面夹住，不得默认降档。

### 时长重算口径（调整后必须照此倒推，禁止自填）
```
可拆时长 ≈ 纯台词字数（对白+独白）÷ 4.5 字/s（参考语速）
          ＋ △动作行数 × 动作拍权重（对话型 1.5s / 混合 2.5s / 行动型 4.0s）
          ＋ 断章留白 3~5s
```
- **动作行字数不参与**时长换算；严禁用氛围 △ 行凑字数、凑时长；
- 调整后的【本集时长】必须与可拆时长对得上（E16 容差 ±20%）——**允许调短，不允许虚标**。

### 红线（不可反向）
- **严禁为凑时长/凑回合加人、加场景突破 ≤4**；
- 配额是"砍别的、保配额"，不是"砍配额、保时长"——任何冲突都以配额为最终赢家。

## 五、机检 E24

```bash
python scripts/validate_episode.py <单集剧本.md> [--format standard|long|manju] [--ref-images N]
```

- **默认上限 4（第一硬性规则）**，超限 **FAIL**。
- `--ref-images N`：改上限（例如你的生成管线确实能给 8 张，就 `--ref-images 8`；属显式覆盖）。
- `--ref-images 0`：**关闭**本项检查（纯剧本交付、不接生成管线时用）。
- 输出固定多打一行：`单集配额：场景 2 + 人物 2 = 4 / 4（第一硬性规则，优先于时长）`，一眼可核对。

### 批量核对
写完一批，逐集跑并抓 E24（**0 行 = 全部合规**）：

```bash
# Windows PowerShell
1..80 | ForEach-Object {
  python scripts/validate_episode.py ("episodes/EP{0:d2}.md" -f $_) --format standard | Select-String "E24"
}
```

连写批量场景也可先跑 `python scripts/export_net_band.py <episodes 目录>` 看全体体量，
再逐集处理配额。

## 六、实战基线（《六十岁，我不伺候了》80 集）

- **≤5 口径（v4.4）首轮统计**：**33/80 集超标**（人物名册普遍 5~7 人，最高 8）。
- 修复手法分布：**①合并工具位 ~12 集 · ②降为画外/动作 ~15 集 · ③台词承接改写 ~6 集**。
- 修复后：**0/80 超标**，且单集机检 80/80 PASSED、`validate_series` PASSED——
  **说明"减配额"与"保伏笔/反转/连续性"可以同时成立**。
- **≤4 口径（v4.5）更严，首轮超标集数会多于 33**：修法与收敛路径完全相同，
  判据仍是修复后 **0 集超 4**；装不进 4 配额的长集按 §四 处理 B 拆集、处理 C 裁定。
- 典型超标集与修法：
  - EP01~EP04（5 人）→ 删"小满"，改里屋灯光一笔带过（1 场 + 3 人 = 4）。
  - EP02/EP05（中介甲+乙）→ 合并为"中介"，台账同步并表。
  - EP71（含公职功能位）→ 《民法典》改由周玉兰自带小册子念，公职角色不入名册。
  - EP80（2 场 + 6 人）→ 场景合 1，删 3 个收尾群像（王婶/三叔/陈志远，改背光侧影）；
    若压完仍撑不满时长，按处理 C 标【配额裁定】。

## 七、和 E3 / E16 / E17 的关系（v4.5 优先级）

- **E3** 只管**场景**（标准档 ≤2 / 长档 ≤3），是"单集能不能在一两个空间里讲完"的剧作约束。
- **E16** 管长档**时长虚标**（标注 > 可拆 ×1.2）、**E17** 管长档**时长下限**（<150 秒）。
- **E24（本规则）** 管**场景 + 人物之和 ≤4**，是"这集能不能被一次生成出来"的生产约束。
- 两者独立，可能一个过、一个不过：1 场 + 4 人 = E3 过、E24 超。
- **口径优先级（v4.5 明确）**：**E24 第一硬性规则 > E16/E17（时长）> E1（体量参考）> 工艺层**。
  E3 的场景上限与 E24 同时成立；凡冲突——包括长档时长下限——一律以 E24 为准，
  按 §四 保配额、调整单集时长（缩短 / 拆集 / 配额裁定降档）。
